Primary User Definition

The primary users of the DFA Passport Appointment System are Filipino citizens who go online to schedule a passport appointment and check which requirements to prepare. We focus on two groups:

User groupDescription
First-time applicant Applying for a passport for the first time. Not familiar with the steps or requirements, so they rely heavily on on-screen instructions and need clear guidance on what to do next.
Returning applicant Has used the appointment system before (e.g., for renewal). Knows the general flow but still has to read through long pages and re-enter the same personal details each time.

Decision Log

Entry #1 – Primary user and user stories

September 24, 2026 · Milestone 2

We interviewed users of the DFA Passport Appointment System using the five questions in Appendix D. Three interviews are complete (two first-time applicants and one returning applicant); a fourth interview with another returning applicant is still being arranged.

Primary user decision: We defined the primary user as Filipino citizens booking a passport appointment online, split into first-time and returning applicants, because the interviews showed the two groups struggle with different things. First-time applicants mostly got lost in the process, while the returning applicant was mainly annoyed by re-entering the same details.

Common problems we heard:

  • Too much text on the page, making it hard to find the next action (all three users).
  • Buttons and links that did not look clickable (all three users).
  • No indication of progress or how many steps are left (User 1, User 3).
  • No immediate feedback when the contact number was typed wrong (User 2).
  • Having to re-enter personal details on every visit (User 3).

Result: Four user stories (US1–US4) were written from these answers, each linked to at least one real user. US5 is reserved for User 4's interview.

Interview Notes (Round 1 – Elicitation)

Short summaries of each interview. No names or identifying details are recorded.

User 1 – First-time applicant
  • Came to book a passport appointment and learn the requirements and steps.
  • Had to read a lot of text before finding the appointment option.
  • Unsure if some buttons were clickable; had to look around the page.
  • Wished the site showed the current step and how many steps are left.
  • Would simplify the page, reduce text, and make buttons look clickable.
User 2 – First-time applicant
  • Came to apply for a passport, book an appointment, and check requirements.
  • Wasn't always sure what to do next because of the amount of information.
  • Typed an extra digit in the contact number and the site did not flag it right away.
  • Wished the site checked entries automatically before moving on.
  • Would add clear error messages to the forms.
User 3 – Returning applicant
  • Uses the site to book an appointment and check requirements.
  • Even as a repeat user, still had to read a lot and look for buttons and links.
  • Wished the site remembered previous information and let them continue their appointment details.
  • Would reduce text, make important buttons easier to see, and show progress.
User 4 – Returning applicant (pending)
  • Interview not yet conducted.
